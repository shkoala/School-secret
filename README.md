# The Midnight Feast — School Secret

Иллюстрированный Halloween-квест для подростков 12–13 лет, уровень A2+–B1.

Сейчас опубликованы две связанные сцены:

1. **The Last Normal Hour** — костюмерная: Present Simple, наречия частотности, время, on / in / at.
2. **The Man in the Mirror** — коридор, камеры и зеркало: Present Simple / Present Continuous, stative verbs, значения think и have.

Всего: **6 улик, 24 проверяемых решения и 4 собственных ответа**. В конце первой сцены нажмите **Enter scene 2**. Прогресс, инвентарь и дневник расследования общие.

## Запуск

Откройте `index.html` вместе с папкой `assets` и файлами JavaScript/CSS. Сборка, установка зависимостей и регистрация не нужны. Правильные введённые ответы автоматически открывают следующий шаг; доступны Enter и кнопка проверки.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Все файлы игры уже находятся в корне. Сборка не требуется. Инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Для учителя

Кнопка **Teacher’s desk** содержит ключи и предпросмотр любой сцены; основная игра при предпросмотре сохраняется. `teacher-guide.html` — инструкция и ключи для печати. Для проектора можно включить крупный текст.

Ответы сохраняются только в браузере на текущем устройстве. В **Settings** можно экспортировать/импортировать JSON; поддерживается сохранение из отдельной первой сцены. Открытые ответы проверяются учителем или партнёром.

После второй сцены показывается анонс третьей: **The Forgotten Library**. Она ещё не входит в эту версию.
